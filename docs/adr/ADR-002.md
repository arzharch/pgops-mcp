# ADR-002: stdio transport first, HTTP later

**Status:** Accepted · **Date:** 2026-08-24

## Context
MCP servers can expose stdio or Streamable HTTP. Target users run Claude Desktop,
Cursor, VS Code locally against a local Postgres.

## Decision
Ship stdio-only for v0.1. Design tool layer transport-agnostic so Streamable HTTP can be
added behind a flag post-v1 without touching tools.

## Consequences
- Zero network attack surface at launch; auth problem deferred rather than solved badly.
- Remote/team use cases explicitly out of scope until HTTP lands.
