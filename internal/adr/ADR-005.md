# ADR-005: testcontainers-based integration tests, no guardrail mocks

**Status:** Accepted · **Date:** 2026-08-24

## Context
Guardrails that pass against mocked SQL execution prove nothing — Postgres semantics are
the adversary.

## Decision
All guardrail/migration/explain tests run against real Postgres spun up by testcontainers
(per-session container, per-test schemas). CI runs Linux containers; local dev uses Docker
Desktop.

## Consequences
- Slower suite (~minutes), fully accepted. Correctness > speed here.
- Seeded scenario fixtures (slow queries, big tables) live in `tests/fixtures/sql/`.
